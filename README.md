# Student Management System

## About This Project
This project is a web-based Student Management System designed to manage student records efficiently.  
It allows users to add, update, view, and delete student information through a simple interface.

---

### Features
- Add new students  
- Update student information  
- Delete student records  
- View student list  
- Database integration  

---

### Technologies Used
- PHP  
- MySQL  
- HTML  
- CSS  
- SQL Stored Procedures  

---

### Purpose
This project was created to practice backend development, database management, and CRUD operations.
